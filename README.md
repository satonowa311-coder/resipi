# セブン買い足し連携レシピアプリ (711-recipe-app)

食材写真や手入力による手持ちの食材と、セブン-イレブンの惣菜・調味料を組み合わせてレシピを提案するReactアプリです。

## セットアップ手順 (ローカル実行)

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

## Vercel / GitHub デプロイ手順

1. GitHub に新しいリポジトリを作成し、このフォルダ内の全ファイルを Push します。
2. Vercel (https://vercel.com) にログインし、「Import Project」から GitHub リポジトリを選択します。
3. Framework Preset に 「Vite」が選択されていることを確認し、「Deploy」をクリックします。
